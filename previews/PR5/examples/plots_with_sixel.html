Plots with Sixel ​

SIXEL rendering is not supported by the browser player. Run this example in a SIXEL-capable terminal; it is not part of recording CI.

  • Source and dependencies

  • Provenance

Source ​

julia
using Replay

instructions = """
using FileIO, Sixel, Plots
gr()
buf = IOBuffer()
show(buf, MIME("image/png"), plot(sin, size=(1000, 750)))
buf |> load |> sixel_encode
"""

replay(instructions, julia_project=@__DIR__)
